# Public Narrative Hardening Spec v1

This spec turns roadmap item 15 into a deterministic repository-native public claim-boundary artifact.

The artifact records blocked public overclaims, required qualifiers, replacement wording, source-backed claim boundaries, and browser rendering rules.
It does not claim legal review, marketing approval, certification, external validation, physical mission readiness, or audience-tested comprehension.

## Source Inputs

- public repository docs and claim-boundary docs
- generated review, evidence, optimization, cost, probability, uncertainty, DAG, runtime, and capsule-risk artifacts
- parameter claim registry
- this spec, builder, validator, and implementation module

## Required Artifact

The builder writes `artifacts/public_narrative_hardening.v1.json`.

The artifact must expose:

- forbidden public claims and required public concepts,
- rule rows for certification, validation, mission probability, optimization, cost, runtime, evidence trust, physics backend, capsule survival, and browser rendering boundaries,
- public surface coverage for user-facing docs and browser routes,
- source claim matrix entries that keep upstream evidence gaps visible,
- replacement guidance for unsafe phrasing,
- rollup booleans that keep external wording audit, legal review, audience testing, and public claim approval incomplete.

## Browser Boundary

The browser may render committed narrative-hardening fields.
It must not recompute claim status, suppress blocked claims, soften external evidence gaps, or present the artifact as legal, marketing, certification, or external-review approval.
